# O Povo Digital

Edição digital acadêmica do jornal histórico *O Povo* (1838–1840), desenvolvida com tecnologias de Humanidades Digitais.

O projeto busca ampliar o acesso ao jornal por meio de um website com visualização das páginas em alta resolução e, futuramente, transcrições e dados estruturados.

- **Coordenação:** Profa. Dra. Carla Menegat (Docente de História do IFSul – Campus Gravataí)
- **Bolsista:** Amandah Andrade Silva (Discente do curso Superior de Tecnologia em Análise e Desenvolvimento de Sistemas – IFSul)

## Vínculo e período

Projeto de extensão do IFSul, com execução de setembro de 2026 a agosto de 2027.

## Arquitetura inicial

- **HTML, CSS e JavaScript:** estrutura, aparência e funcionamento do site
- **Cantaloupe:** servidor que entrega as imagens
- **IIIF:** padrão usado para pedir imagens e descrever os documentos digitais
- **Mirador:** visualizador com zoom e navegação entre páginas
- **Manifesto IIIF:** arquivo que informa ao Mirador quais páginas existem e onde estão as imagens
- **XML/TEI:** tecnologia planejada para as transcrições e os dados estruturados
- **GitHub:** versionamento do código e da documentação

## Situação atual

- **Implementado e testado localmente:** Cantaloupe, URLs IIIF, Mirador, manifesto de estudo e navegação entre fotos de estudo
- **Em andamento:** organização do repositório e documentação
- **Planejado:** testes com TIFF e integração das transcrições em XML/TEI
- **Não iniciado:** ordem real das páginas e publicação em servidor

## Preservação

As fotografias originais não ficam neste repositório. O desenvolvimento usa apenas cópias de estudo.
